# Daggerheart Combat Tracker Companion

A Foundry VTT v14 module for the [Daggerheart](https://github.com/Foundryborne/daggerheart) system (Foundryborne).

## Features (v0.1.0)

- **Combat playlist auto-play**: when a combat starts, the GM picks one of up to 3 configured playlists. Music playlists that were playing are paused and resumed from the same track and position when the combat ends.
- **Inline resources** (GM only): HP, Stress and Evasion/Difficulty shown next to each combatant in the combat tracker.

## Compatibility

- Foundry VTT v14
- Daggerheart system 2.13.2+
